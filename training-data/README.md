# Fiction & Arts Training Data

Training data generated from the Aethermoor novel, ChoiceScript game, and creative writing corpus.

## Structure

- `sft/` — Supervised fine-tuning records (JSONL)
- `dpo/` — Direct preference optimization pairs
- `eval/` — Evaluation and benchmark sets

## Source Material

- 22-chapter novel (~70K words)
- ChoiceScript interactive game
- Character profiles, world-building lore
- Spiralverse cross-references

## Usage

This data feeds into the SCBE-AETHERMOORE training pipeline.
See [curriculum manifest](https://huggingface.co/datasets/issdandavis/scbe-aethermoore-training-data) for integration details.
