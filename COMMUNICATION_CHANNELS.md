## 🔐 Communication Best Practices

### **Do:**
✅ Use GitHub Issues for trackable problems  
✅ Use Slack for time-sensitive questions  
✅ Check documentation before asking  
✅ Be respectful and constructive  
✅ Provide context and details

### **Don't:**
❌ Share sensitive data in public channels  
❌ Cross-post the same question everywhere  
❌ Use Slack for long-term reference material  
❌ Expect instant responses (we're human!)  
❌ Bypass the issue tracker for bugs
